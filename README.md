# Fraud Detection Machine Learning App

An end-to-end fraud detection project built with Python, pandas, scikit-learn, logistic regression, and Streamlit.

The project analyzes more than 6.3 million financial transactions and uses a machine-learning pipeline to classify transactions as potentially fraudulent or legitimate.

## Features
- Exploratory data analysis in Jupyter Notebook
- Data preprocessing
- Logistic regression classification
- Class balancing
- Scikit-learn pipeline
- Saved model using Joblib
- Interactive Streamlit web application

## Technologies
Python, pandas, NumPy, scikit-learn, Streamlit, Joblib, Jupyter Notebook
